# Контур: контроль поручений Минобрнауки ЛНР

Автономный MVP упреждающего контроля поручений по минимальному набору реквизитов СЭД. В EXE доступны реестр поручений и показатели пилота.

## Запуск

Для запуска из исходников требуется Python 3.11 или новее, внешние пакеты не нужны.

```powershell
python desktop.py
```

Откроется оконное приложение. Локальная база SQLite `control.db` создаётся при первом запуске из исходников.

### Готовый EXE

Запустить `dist\Kontur.exe`. Это самостоятельное оконное приложение: браузер не требуется. Для работы реестра интернет не нужен; отправка email требует подключения к SMTP-серверу. Постоянная база хранится в `%LOCALAPPDATA%\Kontur\control.db`, поэтому обновление EXE не удаляет рабочие данные.

## Реализовано

- Реестр поручений: номер, исполнитель, подразделение, срок и статус без содержания документа.
- Автоматическая оценка риска: просрочен, критический, высокий, средний или низкий.
- Идемпотентное формирование напоминаний: не более одного на поручение в день.
- Журналирование напоминаний в локальной базе; email-отправка по SMTP после подтверждения специалистом.
- Ручная фиксация фактических показателей пилота. Исходные значения не подставляются.
- Работа только со служебными реквизитами без содержания документов.
- Учебные записи маркируются `ДЕМО` и не должны использоваться в отчётности.
- Импорт поручений из первого листа книги Excel `.xlsx`; дубли номеров пропускаются.
- Цветовая подсветка сроков в реестре: просрочка — красная, критический риск — оранжевый, высокий риск — зелёный.
- Увеличенный шрифт таблицы; подразделение хранится в базе, но не отображается в реестре.
- Даты в реестре отображаются как `ДД.ММ.ГГГГ`; значения и заголовки всех колонок выровнены по центру.
- Строки и столбцы реестра разделены тонкими линиями, высота строк увеличена для читаемости номеров и дат.
- Если в имени исполнителя указано также название министерства, в реестре и фильтре показывается только имя; данные в базе сохраняются.
- Фильтры списка по исполнителю, уровню риска и интервалу сроков; рассылка email по показанным поручениям.
- Редактирование и удаление выбранного поручения, а также полная очистка реестра прямо в оконном приложении.

## Импорт Excel

Для рабочего режима запустите `dist\Kontur.exe` и нажмите `Импорт Excel` в окне программы. Публичная веб-версия в `public/` — отдельное браузерное демо: данные остаются только в `localStorage` текущего браузера, не синхронизируются с базой EXE и могут исчезнуть при очистке данных сайта. В ней нет Excel-импорта или отправки email; вводите только вымышленные записи. На Vercel публикуется только каталог `public/`.

В первых строках файла должны быть заголовки:

```text
Номер документа | Исполнитель | Email исполнителя | Подразделение | Срок исполнения | Статус
```

Колонки `Email исполнителя`, `Подразделение` и `Статус` необязательны. При отсутствии подразделения записывается `Не указано`. Email существующего поручения задаётся кнопкой `Email исполнителя` после выбора строки. Срок может быть обычной датой Excel или текстом `2026-10-01` / `01.10.2026`. Заголовки допускается размещать после вводных строк. Поддерживаются `.xlsx` и `.xlsm` до 10 МБ; старый формат `.xls` нужно предварительно сохранить как `.xlsx`.

## Редактирование списка

Выберите строку и нажмите `Редактировать выбранное` (или дважды щёлкните строку), чтобы изменить номер документа, исполнителя, email, подразделение, срок или статус. Срок отображается и вводится в формате `ДД.ММ.ГГГГ`; внутри базы дата хранится в формате `ГГГГ-ММ-ДД`. После сохранения риск рассчитывается заново. Кнопка `Удалить выбранное` запрашивает подтверждение и удаляет поручение вместе со связанными записями журнала напоминаний. Если удалить все поручения, демонстрационные записи при следующем запуске не восстановятся.

Кнопка `Очистить содержимое` после подтверждения удаляет **все** поручения (в том числе не показанные текущим фильтром) и весь связанный журнал напоминаний. Показатели пилота сохраняются. Пустой реестр остаётся пустым после перезапуска приложения.

## Фильтрация и отправка email

На вкладке контроля введите имя исполнителя (можно часть имени), выберите уровень риска (`Срок нарушен`, `Критический`, `Высокий`, `Средний`, `Низкий` или `Исполнено`), при необходимости укажите срок `с` и `по` в формате `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`, затем нажмите `Применить`. Фильтры применяются одновременно; `Все уровни` не ограничивает список по риску. Кнопка `Сбросить` возвращает полный список.

Для отправки нажмите `Отправить email`: в окне укажите адрес SMTP-сервера, порт, адрес отправителя, при необходимости логин и пароль, выберите `STARTTLS` (обычно порт 587) либо `SSL` (обычно порт 465), подтвердите отправку. Параметры можно задать также переменными `CONTROL_SMTP_HOST`, `CONTROL_SMTP_PORT`, `CONTROL_SMTP_SECURITY`, `CONTROL_SMTP_FROM`, `CONTROL_SMTP_USER`, `CONTROL_SMTP_PASSWORD`. Пароль не записывается в базу, но остаётся в памяти приложения до закрытия окна.

Отправляются только показанные фильтрами **реальные поручения** со сроком в ближайшие 7 дней или уже просроченные, если email исполнителя заполнен. Исполненные поручения и демоданные пропускаются; повторная отправка одному поручению в течение дня не производится. После успешного ответа SMTP запись заносится в журнал с каналом `Email`; неудачная попытка в журнал успешных отправок не попадает. Письмо содержит только номер документа, исполнителя, срок и статус — без содержания документа и вложений. Кнопка `Сформировать напоминания` по-прежнему создаёт только локальный протокол.

## Граница ИБ

По умолчанию `SENSITIVE_MODULES_ENABLED=false`. Маршруты `/api/sensitive/*` возвращают HTTP 403. Переменную нельзя включать только административным решением: до этого нужны модель угроз, перечень допустимых данных, согласованный контур обработки, роли доступа, аудит и утверждённый срок хранения.

EXE не обрабатывает текст документов и не содержит средств проверки орфографии, Word-файлов или сканов. Существующая база поручений сохраняется при обновлении; ранее сохранённые пользовательские слова не используются и не удаляются автоматически.

## Интеграция с СЭД

Для продуктивного пилота адаптер СЭД должен передавать:

```json
{
  "doc_number": "01-12/458",
  "assignee": "Фамилия И. О.",
  "assignee_email": "user@example.org",
  "department": "Название подразделения",
  "due_date": "2026-10-01",
  "status": "В работе"
}
```

Следующий интеграционный шаг: согласовать формат выгрузки, периодичность, SMTP-сервер и способ получения адреса исполнителя. Текст, тема документа и вложения для напоминаний не требуются.

## Конфигурация

- `CONTROL_HOST` — адрес привязки, по умолчанию `127.0.0.1`.
- `CONTROL_PORT` — порт, по умолчанию `8080`.
- `CONTROL_DB` — путь к SQLite.
- `SENSITIVE_MODULES_ENABLED` — защитный флаг, по умолчанию `false`.
- `CONTROL_SMTP_*` — необязательные значения для предзаполнения SMTP-формы в EXE; пароль можно ввести непосредственно при отправке.
